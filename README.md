# 🧠 Codewars C++ Katas

This repository contains my **solutions and attempts** to various C++ katas on [Codewars](https://www.codewars.com/).

The goal of this repo is to:

* Practice and improve **C++** programming skills
* Explore different problem-solving approaches and modern C++ features (C++17/C++20)
* Keep a personal reference of useful C++ patterns, idioms, and techniques

---

## 📌 About the Solutions

* All solutions are written in **C++**
* Some katas may have **multiple attempts or alternative solutions**
* Solutions are written for **clarity, readability, and learning**, not necessarily golfed for the shortest code
* Difficulty levels range across various Kyu levels (starting from 8 Kyu fundamentals)
